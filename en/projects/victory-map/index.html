Victory Map

A web service for the 80th anniversary of Victory: an interactive map of WWII events with geolocation and a timeline, a public section with archive photos and films from Gosfilmofond, a personal account for uploading materials and an admin panel with moderation.

About the project

The system has three parts: a public section with historical materials and the interactive map, a personal account for registered users, and an admin panel for content management.

The core feature is the map, where war events are pinned to a place and a point in time. The materials are archive photos and films from Gosfilmofond of Russia.

Goals
  • An educational and historical resource built on Gosfilmofond archive materials
  • An interactive map of WWII events filtered by place, date and content type
  • Modern UX, responsive layout, multilingual interface
  • Data safety and security, including users’ personal data

Key functionality
  • Public section: timeline and event map with geolocation
  • Filters by place, date and material type — photo or video
  • Personal account: registration, uploading and editing materials, moderation statuses
  • Admin panel: map events, WWII articles, page content, users, moderation queue
  • Multilingual interface with Russian by default; social-network preview markup
